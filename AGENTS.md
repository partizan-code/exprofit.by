# Особенности exprofit.by

- Статический одностраничный сайт: `index.html`, `script.js`, Tailwind CSS 4.1.17. Собственного backend нет. Обзор и команды: [README.md](README.md); техническая навигация: [docs/README.md](docs/README.md).
- Источник стилей — `src/input.css`. Не редактируйте `exprofit.css` вручную: пересобирайте через `npm run build:css`. Поиск классов ограничен явными `@source` для `index.html` и `script.js`; новые источники регистрируйте явно.
- Сохраняйте согласованный тёмный дизайн, адаптивность, sticky header, нативные якоря, skip link, видимый фокус и reduced motion. Изменение дизайна требует отдельного согласования.
- При изменении UTM и CTA сохраняйте список из пяти разрешённых UTM, приоритет параметров назначения и обычные Telegram-ссылки, не зависящие от аналитики. Формат событий описан в [docs/ANALYTICS.md](docs/ANALYTICS.md).
- `npm test` использует подмены DOM и `fetch`. При браузерных проверках изолируйте внешние запросы и переходы **до первой загрузки**, включая Метрику, Google Apps Script и Telegram; порядок — в [docs/TESTING.md](docs/TESTING.md). Не отправляйте реальные аналитические события и тестовые уведомления без разрешения на конкретную операцию.
- Поставка состоит только из пяти файлов, перечисленных в [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md). Не публикуйте сайт без отдельного разрешения владельца; используйте описанные резервное копирование и откат.
- `docs/CONTENT.md` содержит редакционные материалы с пометкой «не для публикации». Исключение из поставки хостинга не скрывает их в публичном Git-репозитории. Изменение состава этих материалов согласовывайте с владельцем; не удаляйте самостоятельно.
