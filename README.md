# ExProfit

Одностраничный русскоязычный сайт-портфолио Python-разработчика для домена `exprofit.by`. Представляет услуги автоматизации, шесть кейсов и порядок работы; кнопки связи ведут в Telegram.

Сайт использует HTML, обычный JavaScript и готовый CSS Tailwind CSS v4.1.17 (версия указана в заголовке `output.css`). Локального backend, менеджера зависимостей и конфигурации сборки в папке нет.

## Структура

| Файл | Назначение |
| --- | --- |
| [index.html](index.html) | Вся разметка: услуги, портфолио, этапы работы, контакты; SEO-метаданные, favicon и подключение Яндекс Метрики. |
| [output.css](output.css) | Готовые стили Tailwind CSS, включая адаптивную сетку и состояния наведения. |
| [script.js](script.js) | Прокрутка к якорям с учётом фиксированной шапки, сохранение query-параметров внутренних ссылок и отправка данных о кликах. |
| [robots.txt](robots.txt) | Разрешение обхода сайта поисковыми роботами и ссылка на sitemap. |
| [sitemap.xml](sitemap.xml) | Карта сайта с единственным URL главной страницы. |

`index.html` подключает `output.css` и `script.js` из той же папки. Локальных изображений и шрифтов нет; favicon встроен в HTML как SVG data URL.

## Локальный просмотр

Установка зависимостей и сборка для просмотра не нужны. При установленном Python 3 откройте терминал в этой папке и запустите статический сервер.

macOS:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Windows (при доступном Python Launcher):

```powershell
py -3 -m http.server 8000 --bind 127.0.0.1
```

Откройте [http://127.0.0.1:8000/](http://127.0.0.1:8000/). Для остановки сервера нажмите `Ctrl+C`. Такой сервер предназначен для локального просмотра; параметры команды описаны в [документации Python](https://docs.python.org/3/library/http.server.html#command-line-interface).

Даже при локальном просмотре страница подключает действующую Яндекс Метрику, а нажатие кнопок связи вызывает внешний обработчик Google Apps Script. Для изолированной проверки блокируйте запросы к `mc.yandex.ru` и `script.google.com` в браузере до открытия страницы.

## Внешние интеграции

- **Яндекс Метрика:** встроена в `index.html`; включены Webvisor, карта кликов и отслеживание ссылок.
- **Google Apps Script:** функция `sendUTMToTelegram()` в `script.js` отправляет POST с JSON: текст кнопки, полный URL страницы и параметры `utm_source`, `utm_medium`, `utm_campaign`, `utm_term`, `utm_content`. Она вызывается двумя кнопками связи. Исходного кода обработчика в папке нет; доставка данных в Telegram по этому проекту не подтверждается.
- **Telegram:** адрес контакта и ссылки на кейсы заданы непосредственно в `index.html`.

Адрес обработчика и настройки аналитики находятся в исходниках, отдельного файла конфигурации нет. Доступность внешних сервисов и обработка отправленных данных не проверены.

## Изменения и размещение

- Тексты, кейсы, ссылки и метаданные редактируются в `index.html`; поведение страницы — в `script.js`.
- `output.css` — готовый результат генерации. Исходный CSS, `package.json` и команда сборки отсутствуют, поэтому воспроизводимая пересборка сейчас не описана. При добавлении классов в HTML проверяйте наличие соответствующих правил в CSS.
- Для размещения достаточно статического хостинга: пять файлов сайта из таблицы должны находиться в одной публичной папке, а главная страница открываться как `index.html`. Конфигурации хостинга и автоматического деплоя здесь нет.
- При смене домена обновите URL в `robots.txt` и `sitemap.xml`. Поле `lastmod` в sitemap сейчас содержит `2025-11-19`; при обновлении страницы указывайте фактическую дату её изменения.

## Проверка изменений

Автоматических тестов и настроенных линтеров в папке нет. После правок проверяйте отображение на узком и широком экране, загрузку CSS и JavaScript, прокрутку кнопки «Смотреть кейсы» и сохранение query-параметров при внутренних переходах. Отправку событий проверяйте на тестовом обработчике.
