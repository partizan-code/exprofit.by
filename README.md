# ExProfit

Одностраничный русскоязычный сайт-портфолио Python-разработчика для [exprofit.by](https://exprofit.by/). Представляет услуги автоматизации, шесть кейсов и порядок работы; ссылки связи ведут в Telegram.

Статическая архитектура: HTML, обычный JavaScript и Tailwind CSS **4.1.17**. Backend и frontend-фреймворки отсутствуют. Готовый `output.css` хранится в репозитории, поэтому для просмотра и размещения Node.js не требуется.

## Возможности и структура

- Адаптивные блоки услуг, портфолио и этапов работы.
- Нативная навигация по якорю с отступом под фиксированную шапку, видимый клавиатурный фокус и поддержка `prefers-reduced-motion`.
- Сохранение пяти UTM-параметров при внутренних переходах и необязательная отправка события при нажатии контактных CTA.
- Яндекс Метрика, canonical, текстовые Open Graph metadata, `robots.txt` и sitemap.

## Сборка CSS

Требуются Node.js **22+** и npm. Выполняйте команды из корня репозитория; они одинаковы для macOS и Windows:

```sh
npm ci --ignore-scripts
npm run build:css
```

Для автоматической пересборки при изменениях:

```sh
npm run watch:css
```

`tailwindcss` и `@tailwindcss/cli` закреплены на версии 4.1.17; lockfile фиксирует остальные зависимости. Исходник явно сканирует только `index.html` и `script.js`, поэтому примеры в README и тестах не влияют на CSS. При добавлении нового файла с Tailwind-классами зарегистрируйте его через `@source` в `src/input.css`. Подход соответствует [документации Tailwind CLI](https://tailwindcss.com/docs/installation/tailwind-cli) и [настройке поиска классов](https://tailwindcss.com/docs/detecting-classes-in-source-files).

## Локальный просмотр

Установка зависимостей и сборка для просмотра готового сайта не нужны. При установленном Python 3 запустите статический сервер.

macOS:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Windows с Python Launcher:

```powershell
py -3 -m http.server 8000 --bind 127.0.0.1
```

Откройте [http://127.0.0.1:8000/](http://127.0.0.1:8000/). Для остановки нажмите `Ctrl+C`. Сервер предназначен только для локального просмотра; параметры описаны в [документации Python](https://docs.python.org/3/library/http.server.html#command-line-interface).

Страница сохраняет действующие интеграции и при локальном просмотре. Перед открытием изолируйте браузер: блокируйте `https://mc.yandex.ru/*`, `https://script.google.com/*` и `https://script.googleusercontent.com/*`; при проверке CTA подменяйте также переходы к `https://t.me/*`. Автоматизированная проверка должна перехватывать запросы до первой загрузки страницы. Проверка настоящей доставки аналитики требует отдельного тестового окружения.

## UTM и внешние интеграции

Список разрешённых параметров: `utm_source`, `utm_medium`, `utm_campaign`, `utm_term`, `utm_content`.

- Якорь `#portfolio` обрабатывается браузером: query текущей страницы сохраняется, hash и история переходов работают без JavaScript. Плавная прокрутка включается только при `prefers-reduced-motion: no-preference`.
- Внутренние ссылки того же origin получают только UTM текущей страницы. Собственные query-параметры и hash назначения сохраняются; заданные в ссылке UTM имеют приоритет. Остальные параметры текущего URL не копируются. Внешние ссылки, включая Telegram, не получают UTM.
- **Google Apps Script:** `sendUTMToTelegram()` отправляет POST с JSON: `button`, `url` и пять UTM-полей (отсутствующие — `null`). Поле `url` содержит адрес страницы, только разрешённые UTM и hash. Адрес обработчика и названия полей сохранены. `fetch` использует `keepalive`; переход по обычной CTA-ссылке не ожидает ответа и работает при сбое или отключении JavaScript. Исходного кода обработчика здесь нет; доставка в Telegram не подтверждена.
- **Яндекс Метрика:** исходные идентификатор и настройки сохранены, включая Webvisor, карту кликов и отслеживание ссылок. `noscript` с пикселем находится в `body`.
- **Telegram:** контакт и ссылки на кейсы заданы в HTML. Публичная страница `exscreener_bot` на 26 ноября 2026 года называется **Bliss** и описывает салон красоты в Гомеле, что согласуется с тематикой первого кейса; функции бронирования без запуска бота не проверены. Страницы Pon4hBot, CoinRadar24 и realt_by_gomel подтверждают общую тематику соответствующих кейсов. Страница Bybit-бота содержит только имя и предложение связаться; ссылка `addlist` показывает папку «Наши каналы». Детали функциональности и количественные результаты кейсов требуют подтверждения владельца.

## Проверки

```sh
npm test
node --check script.js
npm run build:css
```

`npm test` использует встроенный Node.js test runner и подменяет DOM и `fetch`. Семь тестов проверяют UTM-список, кодирование и повторяющиеся значения, внутренние и внешние ссылки, сохранение query/hash назначения, отсутствие отмены навигации, состав события и сетевые сбои. Production-сервисы не вызываются.

При технической подготовке выполнены локальная проверка HTML5-разметки и изолированная браузерная проверка Chrome при ширине **375, 768 и 1440 px**: отображение, Tab/Enter, мышь, якорь, UTM, история переходов, reduced motion и CTA при успешной, неудачной и зависшей аналитике. Браузерные сценарии не входят в `npm test`; после изменений разметки повторяйте их отдельно с перехватом внешних запросов. Проверка в Windows, Safari и Firefox не выполнялась.

## Изменения и размещение

Тексты, ссылки и метаданные редактируются в `index.html`, поведение — в `script.js`, стили — в `src/input.css`. После изменения Tailwind-классов пересоберите и включите обновлённый `output.css` в поставку.

Для размещения достаточно статического хостинга: `index.html`, `output.css`, `script.js`, `robots.txt` и `sitemap.xml` должны находиться в одной публичной папке. Зависимости, исходный CSS и тесты на сервер не требуются. Конфигурации хостинга и автоматического деплоя в репозитории нет.

При смене домена обновляйте canonical, `og:url`, `robots.txt` и sitemap согласованно. `lastmod` отражает дату изменения страницы. Ресурса для `og:image` пока нет; перед следующим этапом подготовьте изображение для социальных сетей и подтвердите ссылки и фактические результаты кейсов.

Технические изменения не меняют содержание, коммерческое позиционирование или статическую архитектуру сайта. Состояние опубликованной версии и доставка production-аналитики в рамках локальных проверок не проверялись.
