# Документация ExProfit

Этот каталог содержит техническую документацию и контентную основу сайта. Для знакомства с проектом и запуска используйте [корневой README](../README.md).

| Документ | Что описывает |
| --- | --- |
| [ANALYTICS.md](ANALYTICS.md) | Разрешённые UTM, внутренние ссылки, формат события CTA и внешние интеграции. |
| [TESTING.md](TESTING.md) | Изолированные тесты, перехват внешних запросов, браузерные сценарии и ограничения проверок. |
| [DEPLOYMENT.md](DEPLOYMENT.md) | Ручная поставка через FileZilla, резервное копирование, кеширование, проверка и откат. |
| [RECOMMENDATIONS.md](RECOMMENDATIONS.md) | Предложения по CI, версионированию ресурсов и SEO; не реализованная функциональность. |
| [CONTENT.md](CONTENT.md) | Согласованные тексты, источники и внутренние редакционные материалы. |

`CONTENT.md` не входит в поставку на хостинг, но доступен читателям публичного репозитория. Его раздел 2 с пометкой «не для публикации», продуктовыми гипотезами и вопросами согласования требует решения владельца о дальнейшем публичном хранении. Документ оставлен без изменений.

Инструкции агентам находятся в [AGENTS.md](../AGENTS.md). Публикация сайта выполняется только по отдельному разрешению владельца.
