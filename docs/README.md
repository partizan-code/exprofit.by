| [CONTENT.md](CONTENT.md) | Согласованные публичные тексты сайта и расширенные описания проектов. |

## Правила хранения

- Публичные документы в `docs/` и контентная основа `CONTENT.md` отслеживаются Git. В них не размещаются секреты, данные клиентов и внутренние вопросы согласования.
- Внутренние редакционные материалы хранятся локально в `docs/internal/EDITORIAL.md`, автономный прототип — в `docs/internal/design-preview.html`. Каталог `docs/internal/` игнорируется Git и не входит в обычный clone. Старый путь `docs/design-preview.html` также оставлен в `.gitignore`, чтобы случайно не опубликовать новую копию.
- `backup/` в корне проекта содержит локальные резервные копии: они игнорируются Git и не входят в поставку сайта. Их состав не следует менять при работе с документацией.
- `.env` и `.env.*`, кроме `.env.example`, а также `mise.local.toml` остаются локальными. `.env.example` можно отслеживать только с фиктивными значениями и без секретов. Зависимости, логи и системные файлы исключены правилами [.gitignore](../.gitignore).

Локальный прототип можно открыть непосредственно из `docs/internal/design-preview.html` или по пути `/docs/internal/design-preview.html` на [локальном сервере](../README.md#локальный-просмотр). Стили встроены; скриптов и подключаемых внешних ресурсов нет. Внешние ссылки остаются обычными ссылками — при проверке используйте изоляцию из [TESTING.md](TESTING.md#изоляция-браузера).

`.gitignore` исключает неотслеживаемые файлы из обычного добавления, но не ограничивает доступ к данным и не удаляет уже опубликованные версии. См. [официальную документацию Git](https://git-scm.com/docs/gitignore). Редакционный раздел прежнего `CONTENT.md` остаётся в истории репозитория; её переписывание в эту задачу не входит. Для сохранности локальных внутренних материалов нужны отдельные непубличные резервные копии.

Весь каталог `docs/`, включая публичные документы, исключён из поставки на хостинг. Состав поставки и порядок отката описаны в [DEPLOYMENT.md](DEPLOYMENT.md).

Инструкции агентам находятся в [AGENTS.md](../AGENTS.md). Публикация сайта выполняется только по отдельному разрешению владельца.
